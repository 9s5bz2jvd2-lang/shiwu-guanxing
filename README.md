# 食物观星

**食物观星** 是王润圆维护的静态公共学习网页，重点提供：

- 11 个国家卫生健康委食养指南原文入口；
- 食谱快速查询线索（四季食谱、不同地区食谱示例、食养方）；
- 营养科普小工具；
- 观星夜宵、本月星空与公众天文科普。

线上地址：<https://9s5bz2jvd2-lang.github.io/shiwu-guanxing/>

## 11 个食养指南

2023 年：成人高脂血症、成人高血压、儿童青少年生长迟缓、成人糖尿病。

2024 年：成人高尿酸血症与痛风、成人肥胖、儿童青少年肥胖、成人慢性肾脏病。

2026 年：成人脑卒中、成人骨质疏松症、成人肌少症。

本网页只集中整理公开原文入口，不复制指南全文。


新增：页面内已加入“原文与食谱查询库”，首批可查询成人肥胖、儿童青少年肥胖的原文摘录、四季食谱示例与营养方。
