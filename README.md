# 食物观星

由王润圆 / Runyuan Wang 策划维护的静态网页：营养科普、生活方式健康、星空探索，以及 11 个国家卫生健康委食养指南方向的公开原文入口、GitHub 资料包下载与网页内查询。

## 本版新增
- 接入 GitHub `nutrition-assistants` 合集中的 11 个食养资料包入口。
- 网页内可搜索原文蒸馏资料、四季/地区食谱、食养方/营养方。
- 保留国家卫生健康委官方原文入口与部分 PDF 直达链接。

## 文件
- `index.html`：网页主体。
- `styles.css`：高级藕粉色视觉样式。
- `app.js`：本地交互与查询逻辑。
- `food-guide-data.js`：从 GitHub 资料包整理出的网页内查询数据。

本页为科普查询入口，不做诊断、处方或个体化治疗建议。正式内容请以国家卫生健康委公开原文为准。
